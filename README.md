## // OVERVIEW

A single-page-app style portfolio for a freelance digital marketer based in Malappuram, Kerala. The whole site lives in one file, `Portfolio.html`, with inline CSS and JavaScript and client-side navigation between sections.

## // FEATURES

- Client-side navigation between Home, About, Services, Portfolio, Blog, Testimonials and Contact views
- SEO metadata: title and description, Open Graph and Twitter tags, canonical URL, and JSON-LD structured data (including an FAQ)
- FAQ sections and call-to-action banners linking to WhatsApp
- Contact form posting through FormSubmit
- Skills, career timeline and credentials sections

## // TECH_STACK

- HTML5, CSS3 and vanilla JavaScript (no build step, no dependencies)
- Google Fonts: Inter and Syne

## // GETTING_STARTED

```bash
git clone https://github.com/sahilmuhd/Portfolio
cd Portfolio
# static site, no install needed
open Portfolio.html   # or double-click the file in your browser
```
